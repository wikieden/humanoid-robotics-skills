# Synchronizing Claims Across Document Variants

Start with the exact correction and its scope. Record the subject, quantity, unit, denominator, time window, actor and evidence level. Attach the underlying evidence in the working notes. Preserve the author's approved wording where it already fits. Agreeing on a number alone cannot resolve whether it covers one trial, one team or a whole program.

1. Map each editable source to the artifacts readers receive, including translations, PDFs, editable exports and bundles when present. Mark which variants are meant to contain the claim. A short overview may legitimately omit it. Identify authoritative sources for each language or audience before editing.
2. Search for the old value, its rounded forms, aliases and adjacent qualifiers. Check charts, captions, table cells and speaker notes when relevant. Apply the correction to the smallest affected passage in each source. Preserve deliberate differences in emphasis and language. If two sources describe different populations, resolve their provenance before making them match.
3. Rebuild affected deliverables from their mapped sources into a clean output location. Extract text from the final files and check value and qualifier together. For images, charts and layout-sensitive pages, render the changed pages and inspect them. Verify that the final bundle contains the checked exports, using member digests when duplicate filenames exist.
4. Record the result separately for source, exported content and rendered page. A passing source search can coexist with an older PDF in a delivery bundle. If a file format cannot be read or rendered, identify that specific verification gap.

**Worked correction.** A draft calls 24 recordings “24 independent trials.” The run ledger shows twelve trials recorded by two cameras each. Keep both counts where the distinction matters. Check that each language retains the units, that a summary can say “12 trials” on its own, and that the PDF included in the delivery bundle matches the rebuilt PDF. A graph with a recordings axis can still legitimately display 24.

**Deliverable.** Return the corrected claim, the affected source-to-export map, any intentional omissions, and the content and layout checks actually performed. Keep unrelated personal or project details out of reusable examples.
