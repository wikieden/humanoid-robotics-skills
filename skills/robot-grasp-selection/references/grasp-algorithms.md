# Choosing a Grasping Algorithm

Check the active configuration and inspect one actual output before benchmarking. In detection-only mode a service can return correct masks and an empty grasp list by design. Record the selected backend and whether it ran on this request.

| Task and available evidence | Algorithm path | Handoff and first acceptance check |
| --- | --- | --- |
| Pick a requested object from clutter using RGB-D | Grounding DINO can locate a target by text, SAM 2 can refine its mask, and CLIP or SigLIP can help resolve a category. Use a point-cloud grasp backend such as GraspNet-baseline or Graspness to propose 6-DoF gripper poses. | Return candidate poses, widths, scores, frame, and capture time. Inspect full-scene collision filtering, near-duplicate suppression, and whether the remaining candidates still cover multiple approach directions. [GraspNet baseline implementation](https://github.com/graspnet/graspnet-baseline) |
| Clear a tabletop with a small, known set of target classes | A task-specific detector such as YOLOv10s followed by SAM 2 can separate removable objects from regions requiring cleaning. For a removable object, GPD (Grasp Pose Detection) is another point-cloud grasp generator. | Pass the selected object and surrounding obstacle geometry to planning. Among feasible candidates, compare proposal score, joint-limit margin, and viable IK branches. Keep the initial proposals fixed when testing a new ranking rule. |
| Grasp a known rigid object with dimensions or a template | For a box, initialize axes with PCA and fit an oriented bounding box constrained by the known dimensions. For a template, use coarse alignment followed by multiscale ICP. A visible handle or other asymmetric feature can resolve competing yaw hypotheses. | The output is an **object pose**. Compose it with an object-relative grasp transform to obtain a **gripper pose**. If the distinguishing feature is hidden, carry the alternatives into planning or request another view when the task requires a specific side. See [Object Pose Registration](../../robot-object-registration/SKILL.md). |
| Perform a continuous manipulation task with aligned demonstrations | A VLA such as π0.5 or a WAM such as FastWAM can learn an action chunk spanning reach, closure, and transfer. Inspect camera inputs, action representation, gripper units, and chunk duration for the selected checkpoint. | The output is an **action sequence**. Check action scaling and controller supply intervals, then measure object retention and placement across complete attempts. See [Policy Training](../../robot-policy-training/SKILL.md) and [Policy Evaluation](../../robot-policy-eval/SKILL.md). |

## Follow an explicit grasp through execution

1. Transform the proposal into the planning frame at capture time and compute the pre-grasp, grasp, and withdrawal poses with the intended tool offset. Validate IK continuity, joint margins, and collisions. Recheck the retreat and return with the object attached.
2. Where the active stack uses MoveIt and OMPL, preserve the geometric path and its approach, retreat, and transfer boundaries. Apply the configured time parameterizer, such as TOTG, once per intended phase. Recheck clearance if retiming changes geometry. Inspect the final command using the interpolation mode selected on the controller. See [Trajectory Retiming](../../robot-trajectory-retiming/SKILL.md).
3. Record four distinct outcomes for the same trial: **a grasp proposal was generated**, **the full requested path was feasible**, **the object was retained after lift**, and **the object remained at the intended destination after release**. Keep the number of attempts and mark unobserved stages as unknown. Finger closure alone leaves retention unverified.

**Diagnostic example.** A detector finds a bottle and the grasp planner returns three candidates. One candidate passes pre-grasp IK, but the attached bottle hits the shelf on withdrawal. Record a proposal success and a full-path rejection for that candidate. The next comparison should vary approach direction or retreat geometry while keeping the scene and object fixed. Grip strength becomes relevant once an attempted lift supplies evidence about retention.
